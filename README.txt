TAMIL SELVAN BOOKSTORE — STARTER WEBSITE

Files:
- index.html: website content
- style.css: design and responsive layout
- script.js: demo book buttons
- assets/: put your real cover images here if you later update the HTML

IMPORTANT:
This is a front-end demo only. It does not take payments, store orders, or deliver paid files.
Do not publish it as a functioning shop until payment, order confirmation, secure file delivery,
contact details, refund/terms, privacy policy, and applicable tax requirements are configured.

FREE PREVIEW:
1. Extract the ZIP file.
2. Open index.html in a browser to preview it locally.
3. To make it public for free, you can deploy the files with a static hosting service such as GitHub Pages.
   A free static site does not by itself provide a payment gateway or secure digital delivery.
4. Before taking payments, choose a supported payment provider and complete its own account/KYC setup.
   Never share passwords, OTPs, API secret keys, or bank credentials in chat.

Personalize before launch:
- Replace the demo contact email hello@example.com.
- Confirm your actual book title, price, description, and language.
- Replace sample artwork with your approved cover.
- Add privacy, terms, refund and contact information.
